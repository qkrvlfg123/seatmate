# SeatMate — 같이 갈 사람, 여기서

> K-pop 콘서트 2매 단위 티켓에서 **버려질 한 자리**를, 같이 갈 팬과 안전하게 연결하는 2인석 동행 매칭 서비스 (콘셉트 프로토타입).

K-pop 콘서트 표는 대부분 2매 단위로 팔립니다. 혼자 가면 옆 한 자리는 그냥 버려지는데, 그 빈 옆자리는 같이 가고 싶어 하는 누군가의 간절한 자리이기도 합니다.
빈 좌석이 쌓이면 다음 공연은 더 작은 곳에서 열리고 표는 더 구하기 어려워집니다. **SeatMate**는 버려질 한 자리를 같이 갈 팬과 이어, 팬 생태계의 좌석을 순환시키는 것을 목표로 합니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 서비스 소개 랜딩 — 문제 정의 · 매칭 플로우 · 데모 영상 |
| `app.html` | 양방향 티켓 가이드 + 2인석 동행 매칭 프로토타입 |
| `shorts.mp4` | 서비스 소개 숏폼 데모 |

## 핵심 아이디어

- **양방향 티켓 가이드** — "티켓은 못 사는 게 아니라, 사는 법을 모를 뿐" — 티케팅 과정을 단계별로 안내합니다.
- **2인석 동행 매칭** — 남는 1자리를 같이 갈 팬과 안전하게 연결합니다.
- **좌석 순환** — 버려질 빈 좌석을 줄여 공연 생태계의 수요를 지키는 것을 지향합니다.

## 실행

정적 HTML이라 별도 빌드가 없습니다. `index.html`을 브라우저로 열면 되고, 프로토타입 화면은 `app.html`에서 직접 눌러볼 수 있습니다.

> ⚠️ 실제 결제·본인인증·거래 보호 장치는 포함하지 않은 **콘셉트 프로토타입**입니다.
